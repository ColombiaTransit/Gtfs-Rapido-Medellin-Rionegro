# GTFS Rápido Medellín Rionegro

GTFS feed for the intercity bus service of **Rápido Medellín Rionegro S.A.** between Rionegro (Antioquia) and Medellín (Terminal del Norte and Terminal del Sur), Colombia.

The feed is hand-made and frequency-based (`frequencies.txt`). It was originally published in [ColombiaInfo/ColombiaGTFS](https://github.com/ColombiaInfo/ColombiaGTFS/tree/master/Rapido%20Medellin%20Rionegro).

## Contents

| File | Description |
|---|---|
| `agency.txt` | Rápido Medellín Rionegro |
| `routes.txt` | Rionegro – Terminal Norte, Rionegro – Terminal Sur |
| `stops.txt` | Terminal Rionegro, Terminal Norte, Terminal del Sur, Aeropuerto JMC |
| `trips.txt`, `stop_times.txt`, `frequencies.txt` | Van and microbus services |
| `shapes.txt` | Route shapes |
| `calendar.txt` | Service periods |
