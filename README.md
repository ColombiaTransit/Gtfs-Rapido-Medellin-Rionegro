# GTFS Rápido Medellín Rionegro

GTFS feed for the intercity bus services of **Rápido Medellín Rionegro S.A.** between Rionegro (Antioquia) and Medellín (Terminal del Norte and Terminal del Sur), Colombia.

Download: [`gtfs.zip`](gtfs.zip)

## How it is built

The feed is generated by [`build_gtfs.py`](build_gtfs.py); `shapes.txt` is generated by [`build_shapes.py`](build_shapes.py).

```sh
pip install holidays
git clone https://github.com/mvanlaar/colombia-stops ../colombia-stops
python build_gtfs.py --start 20261101 --end 20271231 --zip
```

Stops come from the central stop registry [mvanlaar/colombia-stops](https://github.com/mvanlaar/colombia-stops):
the registry `stop_id` (e.g. `CO001433`) is the GTFS `stop_id`, and name and coordinates are read
from its `data/stops.csv` (`--stops` to use another path). Stops missing from the registry are added there first.

### Shapes (GraphHopper)

`build_shapes.py` routes each shape through GraphHopper along fixed waypoints: the registry stops plus
via points that keep the route on the right road (autopista, Santa Elena, Llanogrande). Run it whenever
waypoints or stop coordinates change, then run `build_gtfs.py`.

```sh
# own GraphHopper server
GRAPHHOPPER_URL=http://localhost:8989 python build_shapes.py

# public GraphHopper Directions API (free key at https://www.graphhopper.com/)
GRAPHHOPPER_KEY=... python build_shapes.py
```

| Variable | Default | |
|---|---|---|
| `GRAPHHOPPER_URL` | `https://graphhopper.com/api/1` | base URL of the server |
| `GRAPHHOPPER_KEY` | | API key, required for the public API |
| `GRAPHHOPPER_PROFILE` | `car` | routing profile |

Requests use `pass_through=true` (no U-turns at via points), which needs flexible mode (`ch.disable=true`)
on the server.

The feed was originally hand-made in [ColombiaInfo/ColombiaGTFS](https://github.com/ColombiaInfo/ColombiaGTFS/tree/master/Rapido%20Medellin%20Rionegro).

## Sources and assumptions

Times and frequencies follow the operator's route page: <https://www.rapidomedellin.com/rutas/intermunicipales/21>

| Service | Vehicle | Hours | Headway |
|---|---|---|---|
| Rionegro ↔ Terminal del Norte, vía autopista | Van | 04:30–22:00 | 6 min in weekday peaks, otherwise 15 min |
| Rionegro ↔ Terminal del Norte, vía autopista | Microbus | 04:30–22:00 | 7 min in weekday peaks, otherwise 15 min |
| Rionegro ↔ Terminal del Norte, vía autopista | Bus | 05:00–20:00 | 15 min |
| Rionegro ↔ Terminal del Sur, vía Santa Elena – aeropuerto JMC | Bus | 05:00–20:00 | 30 min |
| Rionegro → Terminal del Norte, vía Llanogrande – aeropuerto JMC – autopista | Bus | 06:00–18:00 | 60 min |

- The operator gives ranges for vans (6–15 min) and microbuses (7–15 min) "depending on demand". The feed uses the low value in weekday peaks and the high value otherwise.
- Weekday peaks are assumed to be 05:00–08:30 and 16:30–19:30. Colombia has no official definition.
- Colombian public holidays (from the [`holidays`](https://pypi.org/project/holidays/) package) that fall on weekdays run the weekend pattern (`calendar_dates.txt`).
- The feed is frequency-based. Travel times (about 60 min via autopista, 90 min via Santa Elena or Llanogrande) are estimates.
- The Llanogrande route is listed by the operator only from Rionegro. Its via point at Llanogrande is approximate.
